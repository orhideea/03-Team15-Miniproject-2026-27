# Documentation

Project documentation for the Team 15 meeting timer.

| File | Contents |
|---|---|
| `project_overview.md` | Project goal, deliverable checklist, team roles, approach, and known limitations |
| `state-chart.md` | State chart and main-loop flowchart (Mermaid, renders on GitHub), plus the button and LED reference |
| `device-photo.jpg` | Photograph of the assembled breadboard build |

The video of the device in operation is stored in the team Google Drive folder
under `/video` rather than in the repository, and is linked from the root
`README.md`.

Diagrams are written in Mermaid instead of being exported as images so that the
source stays in version control and can be reviewed in a pull request like any
other change.
